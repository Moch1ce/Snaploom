# Triage 标签

工程技能使用五个标准 triage 角色。本文件将这些角色映射到仓库 issue tracker 中的实际标签。

| 技能中的角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估和分类该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已完整定义，可交由 Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实现 |
| `wontfix` | `wontfix` | 不会处理或采纳 |

当技能提及某个 triage 角色时，使用表中对应的 GitHub 标签。
