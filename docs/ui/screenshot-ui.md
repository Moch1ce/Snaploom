# 截图界面视觉规范

Snaploom 的截图浮层及后续编辑工具统一采用轻量、克制的悬浮工具风格。

## 视觉基准

- 选区使用品牌绿色描边，并在四角与四边中点显示共 8 个控制点；选区内保持原始亮度，选区外覆盖半透明黑色遮罩。
- 尺寸标签使用近黑色圆角底和白色文字，显示物理像素尺寸，例如 `514 × 295`。
- 工具栏使用白色悬浮面板、细边框、8px 圆角和轻阴影；整体高度为 44px，左右内边距为 14px，不额外增加上下内边距。
- 每个工具占用 40×40px 命中区域，工具图标使用 18px 线性图标，相邻工具中心间距为 40px；图标与 24px 状态背景之间保留 3px 内边距。
- Hover 时仅在图标后显示 28×28px、4px 圆角的 `#F2F2F2` 背景；选中态保持 24×24px 并使用更深的 `#EDEDED`，两种状态都不给整个按钮铺底。普通操作使用深色，退出使用红色，完成使用品牌绿色。
- 工具组之间使用 1px 分隔线，分隔线左右各留 10px 间距。
- 矩形、箭头、文字和马赛克的专属设置使用带三角指示的白色提示窗，锚定在对应工具按钮下方；打开设置不得改变主工具栏的宽度或按钮位置。
- 工具设置提示窗必须作为截图窗口根布局中的独立同窗浮层承载，不使用原生独立 `Popup`；这样既能保持置顶截图窗口内的鼠标命中链，也能随主浮层一起隐藏，避免阻挡原生保存对话框。
- 输入中的文字编辑框使用透明背景、2px 小圆角和中性细边框，不显示系统主题自带的蓝色焦点边框；四角显示克制的小圆形控制点，插入光标使用品牌绿色，选中文字使用低透明度品牌色；编辑框从紧凑尺寸开始，随内容增长但不得超出选区。
- 未实现的工具必须明确呈现为不可用状态，不得伪装成可点击功能。

## 布局规则

- 尺寸标签默认位于选区左上方 4px；空间不足时放到选区内部。
- 工具栏默认位于选区下方 8px，并与选区右边缘对齐。
- 底部空间不足且选区足够容纳工具栏时，工具栏放到选区内部右下角，并与选区的实际右边和下边都保持 16px；即使选区跨过 macOS Dock 或 Windows 任务栏，也不得按工作区裁剪内部工具栏的位置。选区无法容纳时才翻转到上方。
- 尺寸标签及位于选区外部的工具栏与显示器工作区边缘至少保持 8px 间距，不得进入 macOS Dock、菜单栏或 Windows 任务栏区域；位于选区内部的工具栏跟随截图浮层显示在系统界面上方。

## 组件与令牌

代码中的视觉来源以以下组件为准：

- `ScreenshotUiTheme`：颜色、遮罩、圆角、阴影、按钮及图标尺寸。
- `ScreenshotToolbar`：截图编辑工具栏结构和按钮状态。
- `ScreenshotToolbarIcon`：跨 macOS 与 Windows 一致的矢量线性图标。
- `ScreenshotFloatingUiLayout`：尺寸标签和工具栏的自适应定位。

后续新增矩形、箭头、文字、马赛克等工具时，应扩展这些组件；专属提示窗和文字编辑框使用的颜色、几何、边框及间距也必须来自 `ScreenshotUiTheme`，不要在窗口或工具实现中复制视觉常量。

浮层几何定位是无平台状态的纯坐标计算，允许通过布局函数测试最终可观察位置，以覆盖 Dock、任务栏和屏幕边缘场景；不要为此暴露额外的产品接口。

## 基础交互

- 截图浮层刚出现且指针尚未离开捕获时的位置时，不显示窗口吸附预览，也不允许原地单击直接吸附；指针移动后才启用窗口吸附。
- 在截图浮层任意位置按鼠标右键立即退出，不复制或保存图片。
- 在截图浮层任意状态按 `Esc` 立即退出，不按层取消工具、草稿、对象或选区，也不复制或保存图片。
- 点击绿色完成按钮或双击选区，将 PNG 复制到系统剪贴板并退出截图。
- 按 `Enter` 复制 PNG 并退出截图浮层；按 `Command+C` 或 `Ctrl+C` 复制相同的最终合成 PNG，但保留浮层、选区、标注和撤销历史。
- 按 `Command+S` 或 `Ctrl+S` 打开只允许 PNG 的原生另存为对话框；打开对话框前必须隐藏截图浮层，避免置顶窗口遮挡对话框。默认名称使用本地时间，后续保存从上次选中目录开始。取消保存必须恢复浮层及原有草稿、活动工具、对象选中态和撤销历史，成功后退出截图。
- 尚未开始任何标注编辑时，在选区内部悬停显示整体移动光标，按住左键拖拽可移动整个截图区域；选区不得移出当前捕获画面，尺寸保持不变。一旦开始过标注编辑，即使撤销或删除后对象为空，也不再允许整体移动选区。
- 点击红色取消按钮立即退出截图，不复制或保存图片。

## 标注交互

- `R` 切换矩形工具，`A` 切换单头箭头工具，`T` 切换文字工具，`M` 切换像素化马赛克工具，`V` 返回选择工具。
- 点击工具栏中的标注工具时打开对应设置提示窗；使用键盘快捷键切换工具时只激活绘制工具，不主动打开提示窗，避免遮挡随后开始绘制的位置。
- 矩形仅使用实线轮廓；箭头使用单头实线以及圆角连接和端点，不提供填充、虚线或双头样式。
- 标注色板固定为红、黄、绿、蓝、黑、白六色，默认红色；线宽固定为 2、4、8 逻辑像素三档，默认 4 逻辑像素。
- 文字使用系统无衬线字体，字号固定为 16、24、32 逻辑像素三档，默认 24 逻辑像素；文字工具激活时，单击空白开始多行输入，单击已有文字直接重新编辑，按住已有文字并超过统一拖动阈值后则移动文字且不进入编辑，`Command+Enter` 或 `Ctrl+Enter` 提交；选择工具下仍使用双击重新编辑已有文字。
- 输入中的文字使用一个可复用的临时 `TextBox` 承接系统输入法和组合输入；它不是标注对象控件。编辑框按内容在剩余选区范围内增长，靠近选区边缘时必须裁限。提交后的文字必须回到 `ScreenshotAnnotationRenderer` 与其他标注统一绘制和导出。
- 马赛克只提供像素化效果，不提供高斯模糊；画笔固定为 16、32、64 逻辑像素三档。轨迹与像素块强度作为非破坏性对象保存，实时预览使用 128 物理像素分块缓存并只重建新增轨迹覆盖的受损分块。
- 标注以相对选区的非破坏性对象保存，后创建对象位于更上层；预览、完成对象与 PNG 导出统一使用 `ScreenshotAnnotationRenderer`，不得修改捕获底图或为每个标注创建独立控件。
- 选择工具按从上到下的视觉顺序命中对象，只选中最上层对象；矩形显示四个角和四条边中点共 8 个控制柄，支持整体移动、沿边缩放和沿角缩放；箭头显示起点与终点两个控制柄，支持整体移动，并可通过拖动任一端点改变长度和方向；两者都支持样式修改。文字在选择工具下支持移动、样式修改与双击编辑，马赛克支持移动、删除和强度修改但不支持缩放。
- 矩形或箭头绘制工具仍激活时，单击命中已有矩形或箭头应优先选中该对象并自动返回选择工具，同时打开绑定到该对象类型的设置提示窗；随后修改颜色或线宽时，必须立即更新当前选中对象，而不是只改变下一个对象的默认样式。
- 悬停在标注对象上显示移动光标；文字工具激活时悬停在已有文字上也显示移动光标，离开文字后恢复文本光标。悬停在矩形边控制柄上显示水平或垂直缩放光标，悬停在矩形角控制柄上显示对应方向的对角缩放光标，悬停在箭头端点上显示端点拖动光标；这些反馈必须与绘制工具的十字光标明确区分。
- `Delete` 或 `Backspace` 删除选中对象，点击空白取消对象选择；`Command/Ctrl+Z` 撤销，`Command/Ctrl+Shift+Z` 重做。
- 用户开始绘制首个标注后，尺寸标签与工具栏位置保持稳定；仍可调整选区边缘，对象保持原屏幕坐标，超出新选区的部分由画布和 PNG 导出共同裁切。
