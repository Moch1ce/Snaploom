# 截图界面视觉规范

Snaploom 的截图浮层及后续编辑工具统一采用轻量、克制的悬浮工具风格。

## 视觉基准

- 选区使用品牌绿色描边，并在四角与四边中点显示共 8 个控制点；选区内保持原始亮度，选区外覆盖半透明黑色遮罩。
- 尺寸标签使用近黑色圆角底和白色文字，显示物理像素尺寸，例如 `514 × 295`。
- 工具栏使用白色悬浮面板、细边框、8px 圆角和轻阴影；整体高度为 44px，左右内边距为 14px，不额外增加上下内边距。
- 每个工具占用 40×40px 命中区域，工具图标使用 18px 线性图标，相邻工具中心间距为 40px；图标与 24px 状态背景之间保留 3px 内边距。
- Hover 时仅在图标后显示 28×28px、4px 圆角的 `#F2F2F2` 背景；选中态保持 24×24px 并使用更深的 `#EDEDED`，两种状态都不给整个按钮铺底。普通操作使用深色，退出使用红色，完成使用品牌绿色。
- 工具组之间使用 1px 分隔线，分隔线左右各留 10px 间距。
- 未实现的工具必须明确呈现为不可用状态，不得伪装成可点击功能。

## 布局规则

- 尺寸标签默认位于选区左上方 4px；空间不足时放到选区内部。
- 工具栏默认位于选区下方 8px，并与选区右边缘对齐。
- 底部空间不足且选区足够容纳工具栏时，工具栏放到选区内部右下角，并与选区的实际右边和下边都保持 16px；即使选区跨过 macOS Dock 或 Windows 任务栏，也不得按工作区裁剪内部工具栏的位置。选区无法容纳时才翻转到上方。
- 尺寸标签及位于选区外部的工具栏与显示器工作区边缘至少保持 8px 间距，不得进入 macOS Dock、菜单栏或 Windows 任务栏区域；位于选区内部的工具栏跟随截图浮层显示在系统界面上方。

## 组件与令牌

代码中的视觉来源以以下组件为准：

- `ScreenshotUiTheme`：颜色、遮罩、圆角、阴影、按钮及图标尺寸。
- `ScreenshotToolbar`：截图编辑工具栏结构和按钮状态。
- `ScreenshotToolbarIcon`：跨 macOS 与 Windows 一致的矢量线性图标。
- `ScreenshotFloatingUiLayout`：尺寸标签和工具栏的自适应定位。

后续新增矩形、箭头、文字、马赛克等工具时，应扩展这些组件，不要在窗口或工具实现中复制颜色、间距和按钮样式。

浮层几何定位是无平台状态的纯坐标计算，允许通过布局函数测试最终可观察位置，以覆盖 Dock、任务栏和屏幕边缘场景；不要为此暴露额外的产品接口。

## 基础交互

- 点击绿色完成按钮或双击选区，将 PNG 复制到系统剪贴板并退出截图。
- 按 `Enter`、`Command+C` 或 `Ctrl+C` 复制 PNG 并退出截图浮层。
- 在选区内部按住左键拖拽可移动整个截图区域；选区不得移出当前捕获画面，尺寸保持不变。
- 点击红色取消按钮立即退出截图，不复制或保存图片。
