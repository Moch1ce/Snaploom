# Snaploom Capture Host

Snaploom Capture Host 是一个可独立启动和安装的 GPL-3.0-or-later 程序。它通过同一登录
会话内的本地 IPC 提供交互式截图，SDK 不会捆绑、下载或静默安装本 Host。

官方 Desktop 包会携带同版本 Host；第三方宿主也可以让用户单独安装本包，或显式传入
Host 可执行文件的绝对路径。修改版 Host 可以使用相同公开协议，不要求 Snaploom 官方签名。

对应源码位于同一版本 Release 的 `snaploom-<版本>-corresponding-source.tar.zst`。
